## About

Nibert Investments is a software portfolio focused on turning ambitious ideas into usable products and infrastructure. The work spans:

- **AI and data:** synthetic code-data generation, multilingual programming datasets, data collection, and training workflows.
- **Web3 and blockchain:** Solidity contracts, multi-EVM gateways, Web3 interfaces, blockchain experiments, and NFT generation.
- **Product engineering:** analytics platforms, PDF tooling, websites, browser automation, and practical productivity applications.
- **Creative computing:** generative art, games, interactive experiences, and experimental builds.
